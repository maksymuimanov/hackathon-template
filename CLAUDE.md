# Hackathon Template

Spring Boot Kotlin backend + Next.js frontend monorepo. In-memory architecture (no database).

## Quick Start

**Backend:**
```bash
cd backend
./gradlew bootRun
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```
