# Hackathon Template Monorepo

Monorepo containing Spring Boot Kotlin backend and Next.js frontend.

## Project Structure

- `backend/`: Spring Boot (Kotlin, Java 25, Gradle) application with Spotless code formatting and JUnit 5 tests.
- `frontend/`: Next.js (TypeScript, Tailwind CSS, shadcn/ui, ESLint, Prettier) web application and UI package library.
